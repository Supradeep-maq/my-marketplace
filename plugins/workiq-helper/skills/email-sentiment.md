# Email Sentiment Skill

Analyze the sentiment and tone of emails.

## When to use

Use this skill when the user asks to:
- Analyze email tone
- Check sentiment of emails
- Understand the mood of recent communications

## Usage

```
What's the sentiment of my recent emails?
Analyze the tone of my inbox
Are my recent emails positive or negative?
```

## How it works

- Work IQ MCP fetches email content
- AI analyzes sentiment and tone
- Returns sentiment analysis (positive, negative, neutral)

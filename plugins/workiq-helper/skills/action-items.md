# Action Items Skill

Extract action items and tasks from emails.

## When to use

Use this skill when the user asks to:
- Find action items in emails
- Get tasks from emails
- Extract to-dos from recent emails

## Usage

```
Extract action items from my last 5 emails
What tasks do I have from recent emails?
Find to-dos in my inbox
```

## How it works

- Work IQ MCP fetches email content
- AI identifies action items and tasks
- Returns structured list of to-dos

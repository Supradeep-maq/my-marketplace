# Email Summary Skill

Summarize emails from your Outlook inbox using Work IQ.

## When to use

Use this skill when the user asks to:
- Summarize emails
- Get a summary of recent emails
- Understand what's in their inbox

## Available tools

The Work IQ MCP server provides email access automatically.

## Usage

```
Summarize my latest email
Give me a summary of my last 3 emails
What are my recent emails about?
```

## How it works

- Work IQ MCP automatically connects to your Outlook
- Fetches email content
- AI summarizes the content
- No configuration needed!
